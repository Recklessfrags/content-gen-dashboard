# Visual directions — v3 (three fully-new, maximally-distinct designs)

_Operator, after the Transmission color work: keep Transmission (colors updated — see
`../directions-v2/transmission-colors/`) and additionally explore **3 fully-new designs** (new
layouts AND new colors), **maximally distinct**, one designed **autonomously by Gemini**. These are
brand-new design languages for the Channels hub — NOT re-skins of Transmission. Grounded in
`../design-research-2026.md` (character-forward) + the color rules (distinct signature, harmonized
traffic-light, brand≠danger, AA both modes). Each is self-contained (verified zero external refs),
ships light + dark (all six rendered + verified @1440), and is honest to the data model._

| # | File | Concept | Signature | Character |
| --- | --- | --- | --- | --- |
| **N1 — Bento Soft** | `design-bento-soft.html` | modular asymmetric **bento** of rounded, soft-shadowed tiles; big gradient Action-Center hero | violet/purple | warm, approachable, premium-consumer "instrument"; scan objects, not a ledger |

| **N3 — Terminal Noir / Avant-Garde** *(Gemini's choice)* | `design-designerschoice.html` | **"high-fashion editorial meets studio telemetry"** — hairline exposed grid, massive italic serif channel names, dense mono data, an inverted hero band | "Broadcast Pink" (magenta) | authoritative, unexpected; frames channels as flagship editorial properties needing exec sign-off |

**The experiment (N3):** commissioned with the entire design left to Gemini — concept, layout, type,
personality, and color. It produced *Terminal Noir / Avant-Garde* with a "Broadcast Pink" signature
and a literal "[ INVERT ]" light/dark toggle. Rationale in its `.md`.

**All three** use a harmonized traffic-light status (green/amber/red) with a **distinct non-red
signature** so red = danger only, and pass AA in both modes.

**Known mock nits (build-time fixes, not design flaws):** N3's header shows a stray "SUPABASE
STUDIO" eyebrow (model pulled it from the stack context — should read the product name); toggle
button labels don't always update on click though the theme switches. None affect the design
language being judged.

**How to judge:** open each `.html`, flip modes, resize to a phone. The pool to choose from is now
**Transmission (+ its teal/brass/indigo palette options)** and these **three**. Pick the design
language you want as Phase 1's; it becomes the full design system every screen is built against.
Mixing/hybridizing is welcome.
