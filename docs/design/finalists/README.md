**Mobile read (412px):** all four reflow cleanly. **3 (Aurora)** is strongest for phone triage (its
approval chips stay in the hero). **1 (Editorial)** is the most elegant but tallest scroll. **4
(Risograph)** reads fine on the hub; the open question is dense screens (tables/threaded lists).
**2 (Night Ops)** is compact and efficient but least distinctive.

**Architect recommendation:** **1 (Editorial)** for the best character↔usability↔longevity balance;
**3 (Aurora)** if you want maximum premium/novelty. Taste is the operator's.
